# **Your Safe Space**

A calming and supportive self-care website designed to help users check in with their emotions, express their thoughts, and build positive daily habits.

## About the Project:

**Your Safe Space** is a self-care website created with the idea of providing users with a small, comforting digital space where they can reflect on their feelings and focus on their well-being.

The website includes different interactive sections for mood tracking, journaling, positive emotions, and daily checklists.

## Features:

-  **Mood Tracker** – Helps users check in with their current mood.
-  **Journaling** – Allows users to write and save their thoughts along with the date and time.
-  **Positive Emotion Section** – Encourages users to focus on positive thoughts and emotions.
-  **Daily Checklist** – Helps users keep track of simple daily tasks and self-care activities.
-  **Calming Design** – Soft colors, cards, animations, and a friendly interface create a comfortable experience.
-  **User-Friendly Interface** – Designed to be simple and easy to navigate.

##  Technologies Used:

- HTML
- CSS
- JavaScript
- PHP

## Purpose:

The main purpose of this project is to create a simple digital space where users can:

- Understand and reflect on their mood
- Express their thoughts through journaling
- Practice positive thinking
- Organize small daily activities
- Take a moment for themselves
